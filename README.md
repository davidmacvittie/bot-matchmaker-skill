# Bot Matchmaker skill

Helps an AI agent find the best consumer AI bot or agent for an everyday job, such as fighting a parking ticket, planning a trip, learning a language or helping an aging parent.

It uses Bot Matchmaker's free public search at https://botmatchmaker.com, which ranks real bots weekly by public numbers (App Store ratings, website rank), not payments.

## Install

```
npx skills add davidmacvittie/bot-matchmaker-skill
```

## What it does

When someone asks which bot or app to use for a task, the skill looks up the top matches on Bot Matchmaker and shares each pick with its Bot Matchmaker page link. No personal details are sent.
